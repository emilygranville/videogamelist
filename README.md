# videogamelist

[![main test](https://github.com/emilygranville/videogamelist/actions/workflows/first-test.yml/badge.svg)](https://github.com/emilygranville/videogamelist/actions/workflows/first-test.yml)
[![app tests](https://github.com/emilygranville/videogamelist/actions/workflows/app-tests.yml/badge.svg)](https://github.com/emilygranville/videogamelist/actions/workflows/app-tests.yml)

An app and website designed to help keep track of video games on different consoles. Games are categorzied by console and listed within the console in alphabetical order. Each game contains a list of the corresponding consoles, allowing you to switch to another console that supports the game from the game.
